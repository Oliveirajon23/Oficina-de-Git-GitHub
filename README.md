# Oficina Prática: Primeiros Passos com Git e GitHub

Bem-vindo(a)! Este repositório foi criado para a nossa oficina introdutória de **Git** (controle de versão local) e **GitHub** (colaboração e hospedagem de código na nuvem).

## 🎯 Objetivos da Oficina
Ao final do encontro, você vai conseguir:
- Entender a diferença entre **Git** e **GitHub**.
- Clonar um repositório e configurar sua identidade local.
- Criar uma branch, fazer alterações, registrar um `commit` e enviar (`push`) para o GitHub.
- Abrir um **Pull Request** e resolver conflitos básicos de merge.

## 📋 Pré-requisitos
Antes de começarmos, certifique-se de ter:
1. Uma conta gratuita no [GitHub](https://github.com/).
2. O **Git** instalado na sua máquina ([Download oficial](https://git-scm.com/)).
3. Um editor de texto de sua preferência (ex.: [VS Code](https://code.visualstudio.com/)).
